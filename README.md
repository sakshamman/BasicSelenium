This project contains the basic Selenium WebDriver test scripts I created during the early stages of my learning journey.
All the practice tests were performed on the sample application:

http://eaapp.somee.com/

The goal of this project was to understand fundamental concepts such as:

1.Locating elements

2.Handling forms and buttons

3.Navigation and waits

4.Basic assertions

5.Browser automation workflow

This repository represents the foundation of my Selenium testing skills as I began exploring automation with Java.
